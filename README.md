# 廃都の拳

さらわれた恋人ミカを救うため、ジンがひとりで暴力集団「デッドエンド団」に立ち向かう、ブラウザで遊べるベルトスクロールアクションです。全5面。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。スマホではタッチ操作、パソコンではキーボードで操作します。

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| 移動 | 矢印キー | 左のレバー |
| パンチ | Z | パンチボタン |
| ジャンプ | X | ジャンプボタン |
| 必殺技（武器を持っている時は武器投げ） | スペース | 必殺ボタン |
| 後ろ攻撃 | B、またはパンチとジャンプの同時押し | パンチとジャンプの同時押し |
| 一時停止 | Esc または P | 一時停止ボタン |

- パンチを当て続けると、ジャブ→ストレート→アッパー→ソバットの連続技になります。
- 敵に向かって歩くとつかみます。前＋パンチで背負い投げ、後ろ＋パンチでスープレックス。
- 必殺技は体力を10%使います。体力が10%以下だと出せません。
